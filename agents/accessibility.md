# Accessibility

Target WCAG 2.2 AA. Use semantic landmarks, visible and unobscured focus, associated labels, and programmatically linked errors. Use native elements first and add ARIA only for semantics they lack. Preserve Tab and Shift+Tab order, Enter and Space activation, and Escape for dismissible overlays where appropriate.

Reuse the native dialog component and verify focus cycling and restoration on dismissal. Give dropdowns a deliberate keyboard contract and password visibility toggles a clear accessible name and state. Respect reduced motion. Verify contrast, touch target size, and reflow in both themes. Follow the [manual verification procedure](../docs/accessibility.md).
